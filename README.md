# 🌐 UniEquip Web  
### University Equipment Inventory & Booking System (Web-Based)

## 📌 Overview
UniEquip Web is a system designed to digitize and manage university equipment inventory and booking processes through a structured web-based platform.

This project focuses on **system design, architecture, and database modeling**, ensuring scalability and efficient workflow management.

## 🧠 Problem Statement
Traditional equipment management systems in universities are often:
- Manual and error-prone  
- Difficult to track and manage  
- Lacking real-time visibility  

---

## 💡 Solution
UniEquip Web provides:
- A centralized system for equipment booking and management  
- Structured database design for scalability  
- Clear system workflows through UML diagrams  

---

## 🚀 Features

### 👨‍🎓 Student
- Browse equipment
- Reserve equipment
- View booking status

### 🛠️ Staff / Admin
- Manage inventory
- Approve/reject reservations
- Update equipment availability
- Generate reports

---

## 🏗️ System Design & Architecture

This project emphasizes **software engineering design principles**, including:

- Use Case Diagrams (user interactions)
- Sequence Diagrams (system flow)
- Class Diagrams (data structure & relationships)
- Database design (entity relationships)

---

## 🛠️ Tech Stack

- **Frontend:** HTML / CSS / JavaScript  
- **Backend:** PHP / Node.js 
- **Database:** MySQL
