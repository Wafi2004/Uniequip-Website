# UniEquip Web

## Overview
A web-based university equipment booking system that allows students and clubs to book equipment based on availability, while admins manage bookings, approvals, returns, and reports.

## Features
- User and admin login
- Equipment listing and booking
- Real-time availability tracking
- Booking approval workflow
- Equipment return management
- Admin reporting dashboard

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: PHP 
- Database: MySQL
- Tools: VS Code, Git, GitHub
